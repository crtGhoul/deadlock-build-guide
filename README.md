# Deadlock Build Guide

Full builds for all 42 playable Deadlock heroes — exact left-to-right buy order, ability priority + 16-step skill-up track, situational items, combos, and alternate builds where a hero genuinely has one.

**Live:** https://crtghoul.github.io/deadlock-build-guide/

`index.html` (exported from the Muse artifact) plus the `assets/` directory with hero portraits, ability icons, item icons, and crosshair previews. The page is fully static — no server needed.
